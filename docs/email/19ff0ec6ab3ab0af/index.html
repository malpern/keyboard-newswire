Keyboard Builders Digest #215: July Switch Sales, NocFree & Review

Keyboard Builders' Digest // Issue #215

Check out this week's editorial with some original content, awesome projects, tips, ideas, discount codes, etc!

Hey y'all,

Here are a few notable keyboard-related posts I thought were worth highlighting this time around:

  • Curious about July’s top mechanical switches? The numbers are in, so here are the community’s current favorites based on real sales data provided by 20 vendors and manufacturers.

  • Review: NocFree's strangely named "&" is a low-profile 75% split keyboard. Wireless, classic staggering, classy aluminum housing.

  • The very first EC/HE dual-sensing switches: XVX Whisper 2-in-1 magnetic silent -- Topre feel via domes, now also for your Hall-effect keyboards. Yummy!

  • Bonus review: The Royal Kludge RK R99 is a mechanical keyboard in the 1800 form factor. Wireless, hotswap, with huge RGB firepower.
  • Open source: Hector by Rick Kross. A 38-key split Hall-effect keyboard.
  • Hanthebot's Boardloaf-HE is a 36-key split keyboard with reversible PCB supporting magnetic switches.
  • A diodeless split with splay: Hectrrs36, also by hanthebot.
  • Oldie but goodie: Apfel's open-source Teenspirit is a 18-key monoblock ergo split keyboard.
  • Created by JR, Sharkfin is an open-source configurator for keyboards built on ROYUAN hardware. Fyi, that's 900 models currently, with some popular ones from Akko, Epomaker, KiiBOOM, etc.
